# MovieBox

## About the Project
MovieBox is a movie application that allows users to explore movies and view movie information using data from The Movie Database (TMDB).

## Features
- Browse and discover movies.
- View movie information.
- Access movie content through a user-friendly interface.
- Retrieve movie data using the TMDB API.

## Technologies Used
- HTML, CSS and JavaScript (as applicable to the project)
- TMDB API
- GitHub for version control
